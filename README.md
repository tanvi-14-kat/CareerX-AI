# CareerX AI 🚀

AI-powered career guidance system for students.

## Problem Statement

Develop an AI-powered career guidance system for students based on skills, interests, and market trends.

## About

CareerX AI is a personalized career guidance platform that helps students discover suitable career paths based on their education, interests, skills, goals, and available study time.

The platform provides:

- AI Career Recommendations
- Skill Gap Analysis
- Personalized Learning Roadmaps
- AI Career Mentor
- Career Market Trends
- Skill Assessment
- Career Simulation
- Progress Tracking

## Core User Flow

Student Assessment
→ AI Career Recommendations
→ Select Career
→ Skill Gap Analysis
→ Personalized Learning Roadmap
→ AI Career Mentor

## Project Architecture

Frontend (React)
        ↓
FastAPI Backend
        ↓
AI / Processing Layer
        ↓
Personalized Career Guidance
